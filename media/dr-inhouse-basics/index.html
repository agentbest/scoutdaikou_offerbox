媒体を自社で運用するか代行に出すかの違い｜何を持ち、何を外に出すか

「媒体は契約したが、運用する時間がない。代行に出すべきか」「代行に出すと、自社に何も残らないのではないか」という相談を受けます。結論から言うと、自社運用と運用代行の違いは「どの作業を誰がやるか」であって、「全部やるか、全部任せるか」ではありません。 自社で持つべき作業と、外に出せる作業を分けると、答えが見えます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーであると同時に、OfferBoxを中心にスカウトの運用代行を行っています。この記事では、当社の運用代行の仕組みにも触れますが、料金や数値は書きません。自社で運用するか代行に出すかの判断を、時間の性質、接点の残り方、作業の切り分けの順で整理します。

自社運用と代行の違いは「誰がやるか」

スカウト型の媒体の運用は、いくつかの作業に分かれます。採りたい人物像を決める、検索条件を設定する、文面を書く、送る、返信する、面談を組む、面談する、選考に乗せる。自社運用では、この全部を社内でやります。運用代行では、このうちの一部を外に出します。

作業自社運用運用代行
人物像を決める社内社内（代行会社は聞く側）
検索条件を設定する社内代行会社（社内の人物像に基づく）
文面を書く社内代行会社（共通部分は社内で確認）
送る・一次返信する社内代行会社
面談を組む社内代行会社が日程調整を担うことがある
面談する・選考する社内社内

表を見ると分かるとおり、代行に出しても、「人物像を決める」と「面談する・選考する」は社内に残ります。ここが外に出ることはありません。代行とは、この2つの間にある作業を外に出すことです。

時間の性質が違う

自社運用の時間は、毎週コツコツです。検索し、書き、送り、返信する。この繰り返しが送る期間中ずっと続きます。この時間が取れる会社は自社運用が回り、取れない会社は止まります。止まり方は掲載型とスカウト型の違いで書いたとおりです。

運用代行の時間は、「最初に人物像を伝える」と「面談以降」に集中します。毎週の作業は代行会社が担い、社内は面談と選考に時間を使います。ただし、面談の日程が合わない、返信が遅い、という形で社内の時間が詰まると、代行会社が送っても先に進みません。

  • 自社運用：毎週の送る時間が要る。取れる会社は接点も経験も自社に残る
  • 運用代行：毎週の送る時間は不要。面談と選考の時間は要る。ここが詰まると止まる

代行に出しても、社内の時間がゼロになるわけではありません。「どの作業の時間が要るか」が変わるだけです。

いま使っている媒体の運用の相談だけでも構いません。どの作業を外に出せるか、一緒に線を引きます。

運用の相談をする

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が運用代行を受けるときに線を引くのは、「採りたい人物像を決める」と「面談以降」は社内、「検索条件・文面の作成・送信・一次返信」は当社、という分け方です。人物像まで当社が決めると、面談に来た候補者と社内の期待がずれ、面接官が「思っていた人と違う」と感じる原因になります。逆に、送る作業を社内に残すと、時間が取れずに止まります。この線引きは、代行に出すかどうかにかかわらず、自社運用でも使えます。「人物像と面談は自分たちで、送る作業は誰かに」と分けると、社内で送る人を決めるときにも、その人の役割がはっきりします。代行に出す前に、この線でいまの作業を分けてみることを勧めます。分けてみて、送る作業の時間が取れないなら代行、取れるなら自社運用です。

接点と経験の残り方が違う

見落とされやすいのが、接点と経験の残り方です。

自社運用では、候補者との接点と、運用の経験が自社に残ります。どの文面が効いたか、どの条件の候補者が来たか、どの時期に送ると承認されやすいか。翌年の運用に活きます。

運用代行では、候補者との接点は自社に残ります。文面は自社の名前で送られ、承認も面談も自社との間で起きるからです。ただし、運用の経験は代行会社側に蓄積されやすい。「どの文面が効いたか」を代行会社が持ち、自社は面談以降しか知らない、という状態になりえます。

この点は、紹介で採る場合と比べると違いがはっきりします。スカウト媒体と新卒紹介の違いで書いたとおり、紹介では接点も経験も紹介会社側にあります。運用代行は、接点は自社に残り、経験は代行会社と共有する形です。

  • 自社運用：接点も経験も自社に残る
  • 運用代行：接点は自社に残る。経験は代行会社と共有する。共有の仕組みが要る
  • 紹介：接点も経験も紹介会社側にある

代行に出すなら、「どの文面が効いたか」「どの条件が承認されやすいか」を定期的に共有してもらう仕組みを、契約時に決めておきます。

代行で止まる原因

代行に出せば止まらない、というわけではありません。代行で止まる原因は、社内側にあります。

  1. 人物像が決まらない：代行会社が聞いても、社内で「どんな人を採りたいか」が固まっていない。検索条件も文面も作れない
  2. 文面の共通部分を確認しない：会社の紹介や募集の内容を、代行会社が下書きしても社内が確認せず、送れない
  3. 面談の日程が取れない：承認された候補者に、社内の面談の枠が用意できない。承認が溜まり、候補者の温度が下がる
  4. 一次返信のあとの返信が遅い：代行会社が一次返信しても、その後の社内からの連絡が遅く、候補者が離れる
  5. 結果を共有しない：面談の結果が代行会社に戻らず、条件や文面の改善ができない

代行に出すのは「送る作業」であって、「決める作業」と「会う作業」ではありません。この2つが社内で回らないと、代行に出しても止まります。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。代行に出す場合でも、社内に残る作業の時間をお伝えします。

媒体選びを相談する

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • 毎週の送る時間が取れる。来年以降も自社で運用したい → 自社運用を先に
  • 送る時間が取れない。面談と選考の時間なら取れる → 運用代行を先に
  • 人物像がまだ決まっていない → どちらでも止まる。先に人物像を決める。代行会社に聞いてもらいながら決める形もある
  • 文面を書ける人がいない → 運用代行を先に。ただし共通部分は社内で確認する
  • 面談の枠が用意できない → 代行に出しても止まる。先に面談の体制を作る
  • 自社運用で止まった経験がある → 止まった作業がどれかを特定してから、その作業だけ外に出す

「全部自社で」か「全部代行で」かではなく、「止まる作業だけ外に出す」が、無駄の少ない形です。

切り替えの順番

自社運用から代行へ、代行から自社運用へ、どちらの切り替えも起きます。

  1. 自社運用→代行：止まった作業を特定する。多くは「送る」。その作業だけ外に出し、人物像と面談は社内に残す
  2. 代行→自社運用：代行会社が持つ経験（効いた文面・条件）を受け取る。送る人を社内で決め、代行会社の文面の型を引き継ぐ
  3. 併用：繁忙期だけ代行、それ以外は自社、という形もある。新卒の解禁後の山の時期だけ送る作業を外に出す
  4. どの形でも：人物像と面談は社内。ここは切り替えの対象にしない

エージェントベストの見解

申し込んだあと、運用代行に出したのに「代行は効かなかった」となる会社に共通するのは、「送る作業を外に出したら、社内の時間もゼロになる」と考えていたことです。当社が代行を受けている経験では、送る作業を当社が担っても、承認された候補者との面談を社内で組めない会社では、承認が溜まるだけで先に進みません。面談の枠が週に1つも取れない、返信が数日空く、面接官が決まらない。この状態で送り続けても、候補者の温度が下がって離れます。代行に出す前に、「承認された候補者と、翌週に面談できる体制があるか」を確認することを勧めます。無ければ、代行より先に面談の体制を作るのが順番です。当社が代行の相談を受けるときも、送る話の前に、面談の枠の話をします。

まとめ

  • 自社運用と運用代行の違いは「どの作業を誰がやるか」。全部か全部でないか、ではない
  • 代行に出しても「人物像を決める」と「面談以降」は社内に残る
  • 時間は、自社運用が毎週の送る時間、代行が面談と選考の時間。代行でも社内の時間はゼロにならない
  • 接点は代行でも自社に残る。経験は代行会社と共有する仕組みを契約時に決める
  • 代行で止まる原因は社内側にある。面談の枠と返信の速さを先に整える

よくある質問

代行に出すと、自社に何も残りませんか

候補者との接点は自社に残ります。文面は自社の名前で送られ、承認も面談も自社との間で起きるからです。運用の経験は代行会社に蓄積されやすいので、効いた文面や条件を定期的に共有してもらう仕組みを、契約時に決めておくと残ります。

代行に出せば、社内の時間は不要になりますか

送る作業の時間は不要になりますが、人物像を決める時間と、面談と選考の時間は残ります。特に面談の枠が用意できないと、承認が溜まるだけで先に進みません。代行に出す前に、翌週に面談できる体制があるかを確認することを勧めます。

御社の運用代行は、どの媒体に対応していますか

当社はOfferBoxを中心に、スカウトの運用代行を行っています。当社がOfferBox・Wantedly・ワンキャリアの販売パートナーでもあるので、媒体の申込と運用の相談を同じ窓口で受けられます。自社運用か代行かの線引きは、3媒体の運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。

  • 人事1人の採用体制一人で回す前提なら、手法を増やすより捨てる判断のほうが重要になる。
