OfferBoxで採りたい学生像を言葉にする｜ペルソナの作り方

「どんな学生を採りたいですか」と聞くと、「優秀な学生」「うちに合う学生」「主体性のある学生」という答えが返ってきます。この言葉のままでは、OfferBoxの検索条件にも、オファー文面にも使えません。ペルソナを作るとは、この言葉を「条件」「志向」「行動」の3つに分けて、検索で絞れる形と、文面で触れられる形に落とすことです。 この記事では、ペルソナの作り方を、活躍している若手社員からの逆算、3つへの分解、1人に絞って書く、面接官との合意、の手順で整理します。ターゲット設計の全体はOfferBoxのターゲット設計で書きました。この記事はその中の「学生像」の部分です。

この作業の目的｜検索と文面と面接の共通の物差しを作る

ペルソナが無いと、3つの場面でずれが出ます。

  • 検索：条件が決まらず、広すぎるか狭すぎる
  • 文面：「なぜあなたに」が書けず、誰にでも送れる文面になる
  • 面接：面接官ごとに「いい学生」の基準が違い、評価が割れる

ペルソナは、この3つの場面で同じ物差しを使うためのものです。検索で絞り、文面で触れ、面接で確かめる。3つが同じ学生像を向いていると、承認された学生と社内の期待がずれません。

ペルソナは「理想の学生」ではありません。「自社で活躍している人の、入社前の姿」です。理想を書くと、存在しない学生を探すことになります。

手順1｜活躍している若手社員から逆算する

ペルソナの元は、社内にいます。入社して数年で活躍している若手社員を、数人思い浮かべます。

  1. 活躍している若手を数人挙げる：職種ごとに。人事だけで選ばず、現場のマネージャーに聞く
  2. その人たちの入社前の共通点を探す：学部、学生時代にやっていたこと、志望していた業界、選考で印象に残ったこと
  3. 共通点と、たまたまの違いを分ける：全員に共通するものが「譲れない条件」の候補。1人だけのものは個性
  4. 逆に、早期に離れた人の共通点も見る：採らないほうがよい傾向が見える。ただし個人が特定される形では書かない
  5. 現場のマネージャーに確認する：「この共通点で合っているか」を聞く

この逆算をすると、「優秀」「合う」という言葉が、「学生時代に自分で何かを立ち上げた経験がある」「業界を絞らずに仕事内容で選んでいる」のように具体的になります。

手順2｜条件・志向・行動の3つに分ける

逆算で出てきた共通点を、3つに分けます。分け方で、検索で使うか、文面で使うか、面接で使うかが決まります。

種類何か例（型）どこで使うか
条件プロフィールの項目で分かること卒年、学部の系統、勤務地に通えるか、必要な資格検索で絞る
志向何を大事にしているか業界より仕事内容で選ぶ、少人数で裁量がある環境を望むプロフィールを読んで文面で触れる
行動学生時代に何をしてきたか自分で立ち上げた経験、長く続けた活動、人前に立った経験プロフィールを読んで文面で触れ、面接で確かめる

「条件」は検索で絞れます。「志向」と「行動」は検索では絞りにくく、プロフィールの自由記述を読んで見つけるものです。この2つを検索で絞ろうとすると、対象がほとんど残りません。絞らずに、読んで、文面で触れる。この使い分けが、ペルソナを運用に活かす要点です。

採りたい学生像を条件・志向・行動に分けるところから、一緒に整理します。相談だけでも構いません。

運用の相談をする

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行を受けるとき、ペルソナは企業に作ってもらいます。当社は「条件・志向・行動」の型を渡し、質問をして引き出しますが、活躍している若手が誰で、その人の入社前の姿がどうだったかは、企業にしか分かりません。ここを当社が想像で書くと、面談に来た学生が社内の期待とずれ、面接官が「思っていた人と違う」と感じます。逆に、ペルソナが企業の言葉で書かれていれば、当社は検索条件と文面をその日のうちに作れます。代行に出す場合も、自社で運用する場合も、ペルソナは社内で書く。この線は動かしません。書き方が分からなければ、型と質問はお渡しします。答えるのは企業です。

手順3｜1人に絞って書く

3つに分けたら、1人の学生として書きます。「こういう学生たち」ではなく、「この学生」です。

  1. 名前をつける：仮の名前でよい。社内で「〇〇さんのような学生」と呼べるようにする
  2. 条件を書く：卒年、学部の系統、通える範囲
  3. 志向を書く：何を大事にしていて、会社を選ぶときに何を見るか
  4. 行動を書く：学生時代に何をしてきたか。1つか2つ
  5. その学生が、自社のオファーを開いたときに何を思うかを書く：「なぜ自分に来たのか」と思う学生が、何が書いてあれば返信するか

5番目が、文面の「なぜあなたに」の元になります。ペルソナが1人に絞られていると、「この学生なら、ここに触れれば読む」が書けます。複数の学生像を1つに混ぜると、誰にも刺さらない文面になります。

職種が複数で学生像が違うなら、ペルソナも職種ごとに1人ずつ作ります。同じなら1人で足ります。

手順4｜面接官と合意する

書いたペルソナを、面接官と共有し、合意します。

  • 「この学生が面接に来たら、通しますか」と聞く：通さないなら、ペルソナがずれている
  • 「この学生に、面接で何を確かめますか」と聞く：行動の部分が、面接の質問になる
  • 面接官ごとの基準の違いを出す：ある面接官は行動を重く、別の面接官は志向を重く見ているなら、どちらを優先するかを決める
  • ペルソナを面接官に渡す：面接の前に読める形で

合意ができていると、承認された学生が面接に来たときに、「検索で絞り、文面で触れ、面接で確かめる」が同じ物差しで動きます。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。ペルソナを作る打ち合わせの時間も含めてお伝えします。

エージェントベストの見解

申し込んだあと、最初の1ヶ月で運用が止まる会社に共通するのは、ペルソナが無いまま送り始めて、承認された学生の面談を誰が何のために行うのかが定まらないことです。送る数は増えるのに、承認された学生を面談する現場が「この学生はうちが求めている学生か」を判断できず、面談の設定が遅れ、学生の温度が下がります。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、運用が回っている会社は、送り始める前に、ペルソナを1枚にして面接官に渡しています。1枚あるだけで、承認された学生を見た面接官が「この学生は会う」「この学生は人事が先に話す」と判断でき、面談が止まりません。送る前に、1枚を作る。それが、最初の1ヶ月を無駄にしない準備です。

まとめ

  • ペルソナは「優秀」「合う」を、検索で絞れる条件と、文面で触れられる志向と行動に分けたもの
  • 元は社内にいる。活躍している若手社員の入社前の姿から逆算する
  • 条件は検索で絞り、志向と行動は読んで文面で触れ、面接で確かめる
  • 1人に絞って書き、その学生がオファーを開いたときに何を思うかまで書く
  • 人事が書き、現場が材料を出し、面接官と合意する。送り始める前に1枚を作る

よくある質問

活躍している若手がまだいません。ペルソナはどう作ればよいですか

創業から日が浅い会社では、社内の若手ではなく、「いま活躍している社員が、新卒だったらどんな学生だったか」で逆算します。あるいは、面接官が「この学生なら通す」と言える学生像を、条件・志向・行動で書きます。理想ではなく、通す基準から作ることが要点です。

ペルソナに当てはまらない学生からの反応は、無視してよいですか

無視はしません。ペルソナは検索と文面の物差しであって、承認された学生を切る基準ではありません。ペルソナ外の学生が承認したなら、文面のどこに反応したのかを見ると、ペルソナの修正の材料になります。

ペルソナを作る打ち合わせは、御社に頼めますか

型と質問をお渡しし、引き出す打ち合わせは当社が行います。ただし、書く内容は企業のものです。当社がOfferBoxの運用代行を受けるときも、最初の打ち合わせの大半をこの作業に使います。3媒体の全体像は3媒体の違いと選び方にまとめています。

あわせて読みたい

  • 求人票・募集要項の書き方求人票は条件の一覧ではなく、読んだ人が自分の一日を想像できる文章であるべき。
  • 住宅手当・社宅・寮地方採用では住まいの条件が志望度を直接動かす。
  • 早期離職・定着早期離職は配属後の問題ではなく、採用時に伝えた情報の問題であることが多い。
  • OfferBoxの費用費用の形が媒体掲載型とは違うため、社内の稟議の書き方も変わる。
  • スカウトテンプレートの運用テンプレートは手を抜くためではなく、毎回の判断を減らして個別化に時間を使うために作る。
  • スカウト運用の内製と外注内製か外注かは費用ではなく、継続できるかどうかで決めるべき。
