OfferBoxで狙った学生が見つからないときの検索の直し方｜4つの原因と直し方

OfferBoxで検索したのに、狙った学生が出てこない。件数が少なく、出てきた学生も「こんな人」と違う。この症状は、「OfferBoxにはその学生がいない」で片づけられがちです。ところが、見つからない原因の多くは、検索の側にあります。結論から言うと、見つからない原因を「譲れない条件が重なりすぎている」「検索の言葉が学生の書く言葉と違う」「その時期にその学生が登録していない」「狙いそのものが狭すぎる」の四つに分け、この順に疑います。条件を一つずつ外して件数の変化を見る、学生の自由記述で使われる言葉に合わせる、時期による母数は管理画面で確認する、「こんな人」を大学名や資格から行動に言い換える。広げる順番を決め、広げない条件を先に決めます。 この記事では、四つの原因と順に疑う理由、それぞれの確かめ方と直し方、広げる順番、広げない条件、分担を整理します。検索条件の組み方の基本はOfferBoxの検索条件の組み方、狙いの決め方はOfferBoxのターゲット設計で書きました。この記事は、それらを「見つからない」という症状から逆に辿るものです。

この作業の目的｜「いない」と「見つけられていない」を分ける

「狙った学生がいない」と「狙った学生を見つけられていない」は、見た目が同じです。前者なら、狙いを変えるか、媒体を変えます。後者なら、検索を直せば出てきます。

目的は、この二つを分けることです。検索を直さずに「いない」と判断すると、いる学生を逃します。

見つからない、四つの原因

原因何が起きているか確かめ方
1. 条件が重なりすぎている譲れない条件を全部かけて、どれか一つで落ちる学生が消えている条件を一つずつ外して、件数の変化を見る
2. 言葉が学生の言葉と違う会社の言葉（職種名、業界用語）で検索し、学生が自由記述に書く言葉と合っていない出てきた数人の自由記述を読み、使われている言葉を見る
3. その時期に登録していない狙った学年・層が、まだ登録していないか、動きが終わっている現在の登録状況を管理画面で確認する
4. 狙いが狭すぎる「こんな人」が大学名・資格・経験で狭く決まっていて、そもそも少ない「こんな人」を行動で言い換えて、条件を作り直す

「1→2→3→4」の順に疑います。「1」と「2」は検索の直し方で、その日に直せます。「3」は時期の問題で、待つか、時期を変えます。「4」は狙いの問題で、社内で決め直します。検索の側から疑うのは、直しやすい順だからです。

1. 条件が重なりすぎている

  • サイン：件数が極端に少ない。出てきた学生は「こんな人」に近いが、数が足りない
  • 確かめ方：条件を一つ外して検索し、件数を記録する。もう一つ外して、また記録する。どの条件で大きく減っているかが分かる
  • 直し方：大きく減らしている条件が「譲れない」かを問い直す。譲れないなら残し、実は「あれば良い」なら外す
  • 「譲れない」は三つまで：四つ以上の譲れない条件は、重なった時点で学生がほぼ消える

条件を一つずつ動かす手順はOfferBoxの検索条件の組み方で書きました。条件を全部同時に変えると、どれが効いたか分かりません。

2. 言葉が、学生の言葉と違う

  • サイン：件数が少なく、出てきた学生が「こんな人」と違う。検索の言葉が、社内の職種名や業界用語
  • 確かめ方：条件を緩めて出てきた学生の自由記述を、数人分読む。「こんな人」に近い学生が、自分の経験をどんな言葉で書いているかを見る
  • 直し方：学生の言葉で検索し直す。「営業」ではなく、学生が書く「人と話す」「提案した」「イベントを企画した」。「エンジニア」ではなく「作った」「プログラム」「アプリ」
  • 一つの狙いに、複数の言葉を試す：学生ごとに書き方が違う

学生は、会社の職種名で自分を書きません。自分の経験を、自分の言葉で書きます。読み方はOfferBoxのプロフィールの読み方で書きました。

いま使っている媒体の運用の相談だけでも構いません。見つからない原因を、いまの検索条件と件数から一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「検索して出てこないのだから、OfferBoxにその学生はいない」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、「いない」と言われた検索条件を見ると、譲れない条件が五つ六つ重なっていて、条件を二つ外しただけで「こんな人」に近い学生が出てくることがあります。もう一つ多いのは、社内の職種名で検索していることです。学生は自分を「法人営業志望」とは書かず、「文化祭で協賛を集めた」と書きます。当社が「見つからない」の相談を受けるとき、最初にやるのは、条件を一つずつ外して件数の変化を記録することと、出てきた学生の自由記述を数人分読んで、使われている言葉を拾うことです。この二つで、「いない」の多くが「見つけられていなかった」に変わります。

3. その時期に、登録していない

  • サイン：条件を緩めても、狙った学年・層の件数が少ない。時期が、狙った層の動きの前か後
  • 確かめ方：現在の登録状況と、狙った層の動きを、管理画面とヘルプで確認する。年度ごとに変わるので、記事や過去の記憶で判断しない
  • 直し方：時期を待つか、いま登録している層に狙いを寄せる。年度の公表内容と自社の方針を確認して決める
  • 待つ場合、送る数を減らして、材料を揃える時間に回す：止めない

時期の問題は、検索を直しても解決しません。年間の動きはOfferBoxの年間スケジュールで書きましたが、現在の仕様と登録状況は管理画面とヘルプで確認してください。

4. 狙いそのものが、狭すぎる

  • サイン：条件を緩め、言葉を変え、時期も合っているのに、少ない。「こんな人」が大学名・資格・特定の経験で決まっている
  • 確かめ方：「こんな人」を書き出し、大学名・資格・経験の条件を、「どんな行動をした人か」に言い換えられるかを見る
  • 直し方：「〇〇大学の△△学部」ではなく、「□□を自分で始めて続けた人」。「✕✕の資格」ではなく、「その資格を取るために何をした人か」。行動で言い換えると、大学名や資格で絞ったときに消えていた学生が出てくる
  • 狙いを変えるのは、社内の決定：人事が一人で広げない。責任者と「こんな人」を決め直す

狙いの決め方はOfferBoxのターゲット設計、大学名で絞ることの考え方はOfferBoxで大学群を条件にすることについてで書きました。

広げる順番と、広げない条件

順番広げるもの理由
1「あれば良い」条件を外す譲れない条件ではないので、外しても「こんな人」は変わらない
2検索の言葉を、学生の言葉に変える狙いは同じで、見つけ方だけ変わる
3大学名・資格を、行動に言い換える狙いの「本質」は保ちながら、絞り方を変える
4学年・地域を広げる狙いが少し変わる。責任者と相談
5職種の狙いを広げる狙いが大きく変わる。募集の見直し

広げない条件は、「これがないと入社後に続かない」ものだけです。「譲れない条件」と「あれば良い条件」を先に分けておくと、広げる順番で迷いません。分け方はOfferBoxの学生の評価基準で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。条件を一つずつ動かして確かめる作業の時間をお伝えします。

媒体選びを相談する

見つからないときに、やらないこと

  • 条件を全部同時に緩めない：件数は増えるが、「こんな人」と違う学生ばかりになり、読む時間が消える。OfferBoxの検索結果が多すぎて絞れないとき
  • 「いない」と判断して媒体を変えない：検索を直す前に変えると、次の媒体でも同じことが起きる
  • 大学名だけで絞り直さない：狭くなる方向に戻る
  • 見つからないまま、出てきた学生に送らない：「こんな人」と違う学生に送っても、承認後に合わない。OfferBoxの承認率が低いときに疑う3つの原因

運用代行や代理店が支えられるのは、原因の切り分け、条件を動かす手順、学生の言葉への言い換えの案、行動への言い換えの案までで、「譲れない」の判断、狙いを広げる判断、送る相手の決定は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは切り分けの話です。「見つからない」と「いない」を、当社は分けて扱います。検索の側（条件の重なり、言葉、時期）を直して出てくるなら「見つけられていなかった」で、その日に直ります。検索を直しても出てこないなら「いない」で、狙いを変えるか、媒体を変えるか、時期を待つかの判断になります。当社がOfferBoxの相談で気をつけているのは、「いない」の判断を、検索を直す前にしないことです。検索を直す前に媒体を変えると、次の媒体でも同じ条件で同じ言葉で検索して、同じように「いない」となります。逆に、検索を直しても本当にいないのに、条件を緩め続けると、「こんな人」と違う学生に送ることになります。どちらにも倒れないために、条件を一つずつ動かした記録を残し、その記録で判断します。

まとめ

  • 見つからない原因は、条件の重なり・言葉の違い・時期・狙いの狭さ、の四つ。直しやすい順に疑う
  • 条件を一つずつ外して件数の変化を記録し、大きく減らしている条件が「譲れない」かを問い直す。譲れないは三つまで
  • 検索の言葉を、社内の職種名から学生が自由記述に書く言葉に変える。出てきた学生の自由記述を読んで拾う
  • 時期の問題は検索では直らない。現在の登録状況を管理画面とヘルプで確認し、待つか、いる層に寄せる
  • 大学名・資格を行動に言い換える。広げる順番を決め、広げない条件を先に決め、全部同時に緩めない

よくある質問

条件を一つ外すだけで件数が大きく変わり、どれを外せばよいか分かりません

大きく変わる条件が、絞りの中心です。その条件が「これがないと入社後に続かない」ものなら残し、「あれば良い」ものなら外します。判断が難しいときは、その条件を外して出てきた学生の自由記述を数人分読み、「こんな人」に近いかを見ます。近ければ、その条件は外してよい条件です。

狙いを広げると、「こんな人」と違う学生に送ることになりませんか

広げる順番を守れば、「こんな人」の本質は変わりません。最初に外すのは「あれば良い」条件で、次に言葉を変え、次に大学名や資格を行動に言い換えます。ここまでは狙いが同じです。学年・地域・職種を広げる段になって初めて狙いが変わるので、そこは責任者と決めます。

検索の直し方は、御社に相談できますか

できます。当社は、原因の切り分け、条件を動かす手順、学生の言葉への言い換えの案、行動への言い換えの案を支えられます。「譲れない」の判断、狙いを広げる判断、送る相手の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

  • 人口減少と採用母集団が構造的に減る前提で、採用以外の手段も含めて人員計画を考える必要がある。
